┌───────────────────────────────────────────────────────────────────────────┐
│ ⚡ ZAP COMMANDS CHEATSHEET                                                │
└───────────────────────────────────────────────────────────────────────────┘

Spider Scan:
  Right-click URL → Attack → Spider

AJAX Spider (for React):
  Right-click URL → Attack → AJAX Spider
  → Better for SPAs

Active Scan:
  Right-click URL → Attack → Active Scan
  → Select Policy: Default Policy
  → Technology: Java, JavaScript, MySQL

View Alerts:
  Bottom panel → Alerts tab
  → Filter by risk: High/Medium/Low

Export Report:
  Report → Generate HTML Report
  → Select Context
  → Save to file

Manual Request:
  Find request in History
  → Right-click → Open/Resend with Request Editor
  → Modify payload
  → Send

┌───────────────────────────────────────────────────────────────────────────┐
│ 🎓 TIPS & TRICKS                                                          │
└───────────────────────────────────────────────────────────────────────────┘

Performance:
  • Reduce threads to 5-10 (avoid overload)
  • Set scan timeout: 30-60 seconds
  • Spider depth: Max 5 levels

Focus Areas:
  • Focus on HIGH and MEDIUM alerts
  • Review false positives carefully
  • Test authentication flows manually

Screenshots:
  • Capture full window (not just alert)
  • Show both request AND response
  • Highlight important findings

Documentation:
  • Note all test scenarios
  • Document protection mechanisms
  • Include recommendations
